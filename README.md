# complexity-theory

A mined dataset of **computational complexity theory** papers — harvested from
public metadata APIs, deduplicated, enriched, expanded along the citation
graph, and exported as flat files to run experiments on.

The scope contract is `SCOPE.md`. The agent's rules are `CLAUDE.md`. The run
procedure is `prompts/mine-dataset.md`.

**No language model is involved.** No API keys, no model calls, stdlib Python
only. The pipeline is ported from a literature-review repo whose *subject* was
LLMs; nothing of that subject survives the port.

## Deliverables

Everything in `dataset/`, generated by `scripts/dataset.py`:

| File | |
|---|---|
| `papers.csv` | One row per paper, 25 columns, every field flattened to a scalar |
| `papers.jsonl` | The same records unflattened, for anything CSV would lose |
| `edges.csv` | `citing_id, cited_id` — the citation graph induced on the library |
| `stats.json` | Counts by status, subarea, venue, tier, year, and source |

`edges.csv` is the *induced* subgraph: an edge is written only when both
endpoints are in the library. That keeps it a closed graph you can compute on
rather than a frontier running off into all of mathematics.

## Quickstart

No dependencies. Python 3.9+, standard library only.

```bash
python3 scripts/search_arxiv.py --queries-file config/queries.txt --max 200
python3 scripts/enrich.py                       # DOIs, venues, missing abstracts
python3 scripts/snowball.py --seed-status included
python3 scripts/dataset.py --edges              # the deliverable
python3 scripts/verify_citations.py --all       # gate: non-zero on error
```

Optional, for the hand-labeled core tier (see `SCOPE.md` § Two tiers):

```bash
python3 scripts/screen.py next --limit 25       # candidates out, as JSON
python3 scripts/screen.py apply decisions.json  # decisions in, in bulk
python3 scripts/screen.py stats                 # coverage breakdown
```

**No API keys.** Every source is free, keyless, and unmetered:

| Source | Job |
|---|---|
| arXiv | search, and the abstract for anything Crossref left blank |
| Crossref | DOIs, published venues, and reference lists (backward snowball) |
| OpenCitations | citing papers (forward snowball) |

Optional environment:

- `SURVEY_CONTACT_EMAIL` — the polite pool for Crossref. Faster and more
  reliable. Defaults to the repo owner's address.

Add no keyed source to this pipeline. A metered or key-gated API fails partway
through an unattended run, which is worse than not having it.

## Layout

```
SCOPE.md                  the scope contract — screening decisions cite this
CLAUDE.md                 operating rules, loaded into every agent session
STATUS.md                 live run state; the handoff if the session dies
config/queries.txt        the query grid for the arXiv harvest
scripts/topic.py          the subject: the complexity vocabulary and subareas
papers/library.jsonl      every paper seen, deduped, one JSON record per line
dataset/                  the deliverable
logs/events.jsonl         every query and its yield
.cache/                   raw API responses (gitignored)
```

The subject lives in exactly three places — `SCOPE.md`, `scripts/topic.py`,
and `config/queries.txt` — plus the venue table in `scripts/common.py`.
Everything else is generic harvest and citation-graph plumbing that does not
know what the papers are about.

## Design notes

**Structured APIs, not crawling.** arXiv carries a full abstract on every
entry, which is what screening runs on. Crossref supplies the published DOI and
the committee that accepted the paper. Web fetching reads specific papers,
never discovers them.

**No year floor.** The reference pipeline screened to 2020 and later. This one
does not, and must not: the field's load-bearing results are decades old. A
smoke test of four seed papers snowballed backward to Natural Proofs (1994),
Impagliazzo–Wigderson (1997), Razborov (1987), and Håstad's switching lemma
work — none of which any keyword query would have surfaced.

**Enrichment is what makes snowballing possible.** Both citation sources are
keyed on DOI, and arXiv supplies almost none, so the Crossref title match in
`enrich.py` is load-bearing. Complexity theory does well here — 14 of 34
records matched a published version on the smoke test, against roughly 1 in 15
in the source repo — because this field publishes its preprints.

**Snowballing is what makes it a dataset rather than a search result.**
Keyword search finds papers that phrase things the way you do. Chasing
references and citations finds the ones that do not, including the foundational
work nobody phrases your way. Both directions are gated on the topic vocabulary
so a run converges.

- backward: Crossref reference lists. Only DOI-bearing entries resolve, and the
  run reports how many were deposited as unstructured text and so were lost.
- forward: OpenCitations. Open citation data only, so a thin result means thin
  data, not an uncited paper — say which in `STATUS.md`.

**Everything is resumable.** Responses are cached on disk by URL, the library
is append-friendly JSONL written atomically, and every script is idempotent. A
crash costs the current batch. Curated fields — status, reason, categories,
priority — are never overwritten by a re-fetch.

**Fabrication is the primary risk.** This field's canonical results have names,
and a name is enough to reconstruct a citation that looks right and is wrong.
`verify_citations.py` re-resolves every DOI against Crossref and every arXiv id
against arXiv, and compares the returned title to the one stored. It exits
non-zero, so it works as a gate. Tested against a planted non-existent DOI and
a planted title mismatch; it catches both.

## Known gaps

**ECCC is not harvested.** The Electronic Colloquium on Computational
Complexity is where much of this field posts first, and it has no API. Papers
that later reach arXiv or a DOI-bearing venue are picked up then; the rest are
invisible here. This is structural, not a bug — but it means a thin subarea is
not evidence of a thin literature until it is accounted for.

**Old records carry thin metadata.** Pre-2000 papers arrive from Crossref
reference lists with no abstract deposited and no arXiv preprint to recover one
from. They are real records with real DOIs, and they are the anchors of the
citation graph, but they cannot be screened from an abstract. `stats.json`
reports `with_abstract` against `papers` so the size of this is always visible.

**Two Crossref quirks are corrected in this repo**, both of which mattered
because they hit exactly the old, foundational records:

- Titles are deposited with inline markup (`<i>P = BPP</i> if <i>E</i>…`),
  which corrupts deduplication. `common.strip_markup` removes it.
- ACM's older proceedings deposit an `event.name` naming no committee ("the
  twenty-sixth annual ACM symposium"), while the container title spells out
  STOC. `crossref._venue` now prefers whichever field names a venue we know.
