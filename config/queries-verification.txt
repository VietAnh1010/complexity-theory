# Query grid for the verification tier (SCOPE.md § verification-complexity).
#
# Same format as queries.txt: one query per line, ` AND ` splits concepts,
# each becomes all:"...". Harvest this file with cs.PL/cs.SE added:
#
#   run.py harvest --queries-file config/queries-verification.txt \
#       --categories cs.LO,cs.PL,cs.SE,cs.CC,cs.FL,cs.CR,cs.DS --max 100
#
# The organising question is the cost of *checking* a program, and whether a
# technique survives contact with a real codebase. Tool names are queried
# directly because they are self-limiting; techniques are paired with a cost
# or scale term.
#
# arXiv matches each concept as a literal phrase. Three-concept ANDs and
# symbol-bearing names (F*, K framework) return nothing — do not add them.
